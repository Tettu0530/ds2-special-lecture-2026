## 1. ポジティブ・フィードバックを遮断する改変

alphaがTMGの取り込み、betaがLacYによるTMGの取り込みであることを考慮する。このとき、dx/dtが$-x+\alpha X_{out} + \beta y$であり、
反応経路の図から、LacY(y) が TMG を取り込む → TMG (x) が増える → LacI の抑制が外れる → それにより LacY がさらに増加するというループがみられる。
このため、$+ \beta y$が y から x に戻る項だと考えられる。

yがLacY-GFPからGFPに変わるとき、GFPはTMGを運ばないため、dx/dtの式における$\beta y$は効力を発揮しなくなる。そのため、以下のような微分方程式になるはずである：
```
dx/dt = -x + alpha * x_out
dy/dt = (x ** 2) / (rho + (x ** 2)) - y # LacIによる抑制と協同性の部分は不変のまま
```

## 2. シミュレーション

```python
import matplotlib.pyplot as plt
import numpy as np
from scipy.integrate import solve_ivp

def ozbudak_model( t , init , *param ):
    x = init[ 0 ]
    y = init[ 1 ]

    [ alpha , beta , rho , x_out ] = param

    dxdt = -x + alpha * x_out # beta * y を撤去
    dydt =  x**2 / ( rho + x**2 ) - y
    
    return [ dxdt , dydt ] 

def ozbudak_dose_response( x_out , y_init , marker ):
    init = [ 0 , y_init ]
    t_span = [ 0 , 60 ]

    alpha = 0.1
    beta = 10
    rho = 25

    param = [ alpha , beta , rho , x_out ]

    solution = solve_ivp( ozbudak_model, t_span, init , method='RK45', args=param )
    
    LacY = solution.y[1]
    y_end = LacY[-1]
    
    plt.plot( x_out , y_end , marker , fillstyle='none') 

    return y_end
    
##
## Main
##

y_init = 0
for x_out in range(11):
    y_init = ozbudak_dose_response( x_out , y_init , 'ko' )

for x_out in reversed( range(11) ):
    y_init = ozbudak_dose_response( x_out, y_init, 'r+')

plt.show()

```
