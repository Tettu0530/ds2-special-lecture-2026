# 発展課題

## 1. ヌルクラインと固定点

dv/dt = 0となるのは、v=0またはu=1 - σ(α + β)=0.94のとき。また、du/dt = 0となるのは、u=0またはv=(α + γ)/ρ = 0.06の時である。
固定点は(0,0)および(v,u)=((α+γ)/ρ, 1 − σ(α+β)) = (0.06, 0.94)の二つである。
この時、v=0やu=0は、経済的に考えて意味がないため、前者は無視できる。


## 2. 相平面とベクトル場から読み取れること

図を見ると、初期値(0.06, 0.92)から出た軌跡は、固定点を囲んでいる閉曲線であり、同じ道を何度も辿っている。vの範囲は0.055〜0.065、uが0.92〜0.96である。
横軸=v、縦軸=uとした時、これらは反時計回りに回る。なぜなら、雇用率が高いv > 0.06ではuが増加し、分配率が高いu > 0.94ではvが減少するためである。
そのため、経済的に見れば雇用率が上がる->賃金および労働分配率が上がる->利潤が減る->投資が減る->雇用率が下がるというサイクルが見える。これが繰り返されることにより景気循環が生まれると考えられる。


## 3. ヤコビ行列と固有値
固定点におけるヤコビ行列は、J = [[0, −(α+γ)/(ρσ)], [ρ(1 − σ(α+β)), 0]]である。
ここに数値を代入すると、J = [[0, −0.03], [0.47, 0]]であり、固有値はλ=±0.1187iであり、純虚数であると言える。


## 4. 固有値による安定性解析

固有値は純虚数であり、実部は0である。そのため、固定点はセンターであり、軌跡は固定点に近づくこともなく、遠ざかることもない。また、漸近安定でも不安定でもない中立安定であると言える。
周期は約2π/0.1187 ≒ 53であり、時系列の約10周期/500とも一致する。

Sel'kov（a=0.06）の固有値は実部が正の複素数で、不安定スパイラルである。軌跡はどの初期値から出ても1本の閉曲線に引き寄せられる。
一方でGoodwinでは、閉曲線は初期値ごとに違う。初期値を変えることで別の大きさの円となり、隣の軌道も閉曲線である。
